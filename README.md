# 🌐 إضافة ترجمة اجتماعات جوجل للعربية | Google Meet Arabic AI Subtitles

إضافة **Chrome Extension** احترافية تترجم اجتماعات Google Meet فورياً وبسياق غير حرفي إلى اللغة العربية باستخدام الذكاء الاصطناعي (Gemini AI).

---

## ✨ المميزات الرئيسية
* 🧠 **ترجمة سياقية غير حرفية:** تعتمد على محرك **Gemini AI** لتوليد ترجمة عربية طبيعية كأنها تدبلج أو تُترجم سينمائياً.
* ⚡ **مجمع الجمل الذكي (Sentence Buffer):** ينتظر تجميع الفكرة كاملة أو وقفة الكلام قبل الترجمة لتفادي الترجمة الحرفية المجزأة.
* 👤 **تحديد اسم المتحدث (Speaker Tagging):** عرض اسم الشخص المتحدث بجانب الترجمة (`[أحمد]: الترجمة...`).
* 🎨 **واجهة زجاجية عائمة (Glassmorphic HUD):** شريط ترجمة أنيق يمكنك سحبه، تكبير الخط فيه، أو تثبيته في أي مكان بالشاشة.
* 📋 **سجل المحادثات والتحميل (Transcript Export):** حفظ المحادثة المترجمة كاملة مع إمكانية تحميلها كملف نصي (`.txt`).
* ⚡ **محرك احتياطي سريع:** يعمل حتى بدون مفتاح API عند الحاجة.

---

## 🛠️ طريقة التثبيت في متصفح Chrome (خلال دقيقة واحدة)

1. افتح متصفح **Google Chrome**.
2. اكتب في شريط العنوان: `chrome://extensions` واضغط **Enter**.
3. قم بتفعيل **وضع المطور (Developer mode)** من المفتاح أعلى يمين الشاشة.
4. اضغط على زر **تحميل إضافة غير محزومة (Load unpacked)**.
5. حدد مجلد المشروع التالي:
   `C:\Users\Video Editor\.gemini\antigravity\scratch\google-meet-arabic-subtitles`
6. مبروك! ظهرت الإضافة الآن في شريط أدوات Chrome.

---

## 🔑 الحصول على مفتاح Gemini API المجاني (لأفضل جودة ترجمة)

1. اذهب إلى [Google AI Studio - API Key](https://aistudio.google.com/app/apikey).
2. سجل بدخولك بحساب Google واضغط على **Create API key**.
3. انسخ المفتاح.
4. اضغط على أيقونة الإضافة في Chrome، اختر محرك **Gemini AI**، والصق المفتاح في خانة API Key واضغط **حفظ الإعدادات 💾**.

---

## 🎯 طريقة الاستخدام أثناء اجتماع Google Meet

1. انضم لأي اجتماع على [Google Meet](https://meet.google.com).
2. قم بتشغيل الـ **Captions (التفريغ الصوتي)** من شريط Google Meet السفلي (زر **CC**).
3. سيظهر فوراً شريط الترجمة العربي العائم أسفل الشاشة بترجمة عربية فائقة الدقة وسلسة!
